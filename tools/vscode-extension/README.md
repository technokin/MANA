# MANA Language Support (v1.0.0)

This optional Visual Studio Code extension provides syntax highlighting, comments, indentation settings, bracket matching, and snippets for MANA `.mana` source files. It includes the MANA logo as the extension icon.

**This extension is editor support only.** It does not parse or execute MANA programs; use the MANA Python runtime in the source repository to run or syntax-check programs.

## Install from VSIX

In VS Code, open **Extensions → `...` → Install from VSIX...** and select `installers/vscode/mana-language-1.0.0.vsix` from the MANA repository.

## Contributing

Improvements to syntax highlighting, snippets, and language-editor metadata are welcome. Contribution guidelines are in the top-level `CONTRIBUTING.md` file in the MANA source repository.
