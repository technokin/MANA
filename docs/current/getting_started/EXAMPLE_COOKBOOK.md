# MANA Example Cookbook

**Page kind:** Practical guide  
**Audience:** people who learn best by running small programs

Each example in `examples/` is a separate `.mana` program. Run it from the repository root with `python mana.py examples/FILE.mana`. Add `--check` before the file name to check syntax without executing it. Use `py` instead of `python` on Windows if that is your Python launcher.

## Start with the language

- [**`standalone_release.mana`**](../../../examples/standalone_release.mana) is a short program to confirm that the interpreter works.
- [**`helper_functions.mana`**](../../../examples/helper_functions.mana) shows that ordinary `def` functions can return calculated values with `incant`.
- [**`conditional_magic.mana`**](../../../examples/conditional_magic.mana) demonstrates branching around a magical operation.
- [**`timed_spell.mana`**](../../../examples/timed_spell.mana) introduces virtual-time statements.
- [**`event_reactions.mana`**](../../../examples/event_reactions.mana) registers a handler for an impact event generated by the runtime.
- [**`impact_handler_counter.mana`**](../../../examples/impact_handler_counter.mana) counts the runtime-reported impacts and verifies target state after contact.

## Objects, movement and contacts

- [**`target_profiles.mana`**](../../../examples/target_profiles.mana) and [**`target_resistance.mana`**](../../../examples/target_resistance.mana) define and inspect target profiles.
- [**`earth_barrier.mana`**](../../../examples/earth_barrier.mana) and [**`anchored_object.mana`**](../../../examples/anchored_object.mana) explore shape labels, anchoring, and movement after unanchoring.
- [**`motion_control.mana`**](../../../examples/motion_control.mana) changes an object's velocity and advances the 2D world.
- [**`distance_check.mana`**](../../../examples/distance_check.mana) uses `geometry2d` for a distance calculation.
- [**`geometry_rotation.mana`**](../../../examples/geometry_rotation.mana) rotates a direction before applying it to an object.
- [**`collision_demo.mana`**](../../../examples/collision_demo.mana) and [**`fireball_contact.mana`**](../../../examples/fireball_contact.mana) show what a runtime-reported contact looks like.
- [**`selective_two_target_cast.mana`**](../../../examples/selective_two_target_cast.mana) chooses one target outside a reusable spell, leaving an unselected target unchanged.

## Elements and combinations

- [**`elements_demo.mana`**](../../../examples/elements_demo.mana) introduces the four fundamental elements.
- [**`elemental_cancellation.mana`**](../../../examples/elemental_cancellation.mana) demonstrates the implemented Fire/Water cancellation rule.
- [**`ice_creation.mana`**](../../../examples/ice_creation.mana) exercises the supported Water/Air-to-Ice interaction.
- [**`wood_from_elements.mana`**](../../../examples/wood_from_elements.mana) and [**`life_and_wood.mana`**](../../../examples/life_and_wood.mana) demonstrate Water + Earth -> Mud and Mud + Life -> Wood where the required channel is available.
- [**`heating_and_cooling.mana`**](../../../examples/heating_and_cooling.mana) separates temperature changes from absolute temperatures.

These are the interactions currently implemented by the runtime; they are not a complete rule system for every possible pair of concepts. See [Elements and Implemented Rules](../reference/ELEMENTS_AND_RULES.md).

## Pure mana: weave it, do not create it

- [**`mana_constructs.mana`**](../../../examples/mana_constructs.mana) uses `weave mana` and demonstrates a visual preview before a real release.
- [**`mana_shield.mana`**](../../../examples/mana_shield.mana) defines a shaped, anchored mana barrier.
- [**`mana_burst.mana`**](../../../examples/mana_burst.mana) demonstrates an area pulse.
- [**`mana_beam.mana`**](../../../examples/mana_beam.mana) demonstrates a directed beam.
- [**`preview_then_release.mana`**](../../../examples/preview_then_release.mana) compares a text preview, a visual preview, and a committed release.
- [**`preview_commit_boundary.mana`**](../../../examples/preview_commit_boundary.mana) checks that a preview does not add a persistent object but release does.
- [**`visual_preview.mana`**](../../../examples/visual_preview.mana) is a compact starting point for the Visual button.
- [**`shape_gallery.mana`**](../../../examples/shape_gallery.mana) puts several supported visual shape labels in one scene.

`weave mana` shapes an ambient magical construct. It does not create a finite supply of mana. An object's stored effect energy is part of the prototype's energy model and must not be presented as a spendable mana pool.

## Beings, planes and remains

- [**`summoning_example.mana`**](../../../examples/summoning_example.mana) demonstrates summoning, naming, returning and recalling a being.
- [**`return_recall.mana`**](../../../examples/return_recall.mana) focuses on the return/recall part of that cycle.
- [**`necromancy_example.mana`**](../../../examples/necromancy_example.mana) reanimates existing remains.
- [**`summon_skeleton_spell.mana`**](../../../examples/summon_skeleton_spell.mana) shows a user-authored spell composed from library operations.
- [**`drafter_define_plane.mana`**](../../../examples/drafter_define_plane.mana) defines custom plane data in memory.
- [**`planes_navigation.mana`**](../../../examples/planes_navigation.mana) works with plane identities and pathways.
- [**`plane_path_lifecycle.mana`**](../../../examples/plane_path_lifecycle.mana) tests a one-way path before and after it is closed.

Plane information is primarily backend rule data. The Visualiser does not draw plane maps, mana routes, portals, or gateways. A successful summon can use a local manifestation effect without showing a portal.

## Optional calculation libraries

- [**`vector3d_planning.mana`**](../../../examples/vector3d_planning.mana) uses 3D vector calculations without pretending the world engine is 3D.
- [**`physics_demo.mana`**](../../../examples/physics_demo.mana) reads motion and physical quantities from the current simulation.
- [**`kinetic_thermal_ledger.mana`**](../../../examples/kinetic_thermal_ledger.mana) combines mass, heating, motion, cooling, and a direct temperature update; a test checks the final energy ledger.
- [**`scatter_stones.mana`**](../../../examples/scatter_stones.mana) creates a small group of objects in a loop.
- [**`advanced_operations.mana`**](../../../examples/advanced_operations.mana) collects additional built-in operations.

## Watch a program run

Install `installers/vscode/mana-magic-visualiser-2.0.0.vsix`, open an example inside the MANA folder, and click **MANA: Visual** (the eye action) in the editor toolbar. This records a run and opens it in the optional viewer. Clicking the ordinary Run triangle does not launch the Visualiser.

For command-line replay, use `python mana.py --record replay.jsonl examples/fireball_contact.mana`, then choose **MANA: Open Visualiser Recording** in VS Code. This JSON Lines file is an internal Visualiser recording, not a public API for Unity, Godot, Unreal, or other external programs.

The [full examples index](../../../examples/README.md) lists every runnable example. For the complete syntax, use the [Language Guide](LANGUAGE_GUIDE.md) and [Language Specification](../language/LANGUAGE_SPEC.md).
