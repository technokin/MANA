# MANA Documentation

The short project introduction is [`../MANA_INTRO.md`](../MANA_INTRO.md). The canonical detailed entry point is [`current/INDEX.md`](current/INDEX.md). Current documentation describes the latest source version; earlier audits and specifications are preserved separately for historical context.

## Current documentation — v2.0.0

- `current/foundations/` — conceptual foundations: mana and energy, elements, spells, planes, beings, necromancy, object control, 2D/3D, libraries, and implementation status.
- `current/getting_started/` — first programs and syntax basics.
- `current/language/` — formal grammar-level rules, keyword vocabulary, spell templates, and tuning.
- `current/reference/` — implemented built-ins, properties, element catalogue, and interaction rules.
- `current/physics/` — physical quantities, ledger, world stepping, collision response, and known limits.
- `current/libraries/` — exact library arguments, return values, validation, errors, and examples.
- `current/internals/` — implementation architecture and source-module roles.
- `current/tooling/` — Python setup and VS Code support.
- `current/troubleshooting/` — common errors and recovery steps.

## Archive and design ideas

- `archive/audits/` — release audits and coverage reports. These describe the named historical release and may mention removed interfaces.
- `archive/v0.6/`, `archive/v0.7/`, and other versioned folders — superseded design/specification records.
- `ideas/` — proposals, not implementation promises.

Do not use an archived audit as the current API reference. Use the current language/library reference and tests.
